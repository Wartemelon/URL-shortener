# internal/config

В этом пакете хранятся конфигурации приложения.

Загрузку конфигурации можно реализовать из различных источников, например: файлов, переменных окружения, баз данных и других.

В данном случае конфигурация должно получать только адрес вашего сервера `localhost:8080` из переменной окружения или флага командной строки. В случае указания адреса и в переменной окружения и в коммандной строке - переменная окружения имеет приоритет.
