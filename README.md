# Простой сервис сокращения URL

Чтобы написать сервис, который будет сжимать длинные URL до нескольких символов, для начала вам нужно разработать сервер. 

Сервер должен быть доступен по адресу http://localhost:8080 и предоставлять два эндпоинта:

- Эндпоинт с методом `POST` и путём `/`. Сервер принимает в теле запроса строку URL как `text/plain` и возвращает ответ с кодом `201` и сокращённым URL как `text/plain`.
Пример запроса к серверу:

```text
POST / HTTP/1.1
Host: localhost:8080
Content-Type: text/plain

https://practicum.yandex.ru/
```

Пример ответа от сервера:

```text
HTTP/1.1 201 Created
Content-Type: text/plain
Content-Length: 30

http://localhost:8080/EwHXdJfB
```
- Эндпоинт с методом `GET` и путём `/{short}`, где `short` — идентификатор сокращённого URL (например, `/EwHXdJfB`). В случае успешной обработки запроса сервер возвращает ответ с кодом `307` и оригинальным URL в HTTP-заголовке `Location`.

Пример запроса к серверу:

```text
GET /EwHXdJfB HTTP/1.1
Host: localhost:8080
Content-Type: text/plain
```

Пример ответа от сервера:

```text
HTTP/1.1 307 Temporary Redirect
Location: https://practicum.yandex.ru/
```

На любой некорректный запрос сервер должен возвращать ответ с кодом 400.

Для хранения сокращенных URL используйте хранилище в памяти(слайс или мапу).

## Как работать с репозиторием

Для начала работы вам нужно:

1. Нажать на кнопку `Use this template`.
2. Создать из шаблона репозиторий на своем аккаунте.
3. Склонировать репозиторий на свой компьютер с помошью команды `git clone`.
4. Создать новую ветку для добавления кода с помощью команды `git checkout -b <имя_новой_ветки>`.
5. Можно начинать выполнять задание.
