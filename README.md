# URL Shortener

URL Shortener — это HTTP-сервис на Go для сокращения ссылок. Сервис принимает длинный URL, генерирует для него короткий идентификатор и позволяет перейти по короткой ссылке обратно на исходный адрес.

Проект реализован как backend-сервис с двумя основными сценариями: создание короткой ссылки и редирект по короткому идентификатору. Для создания ссылки используется эндпоинт с методом `POST` и путём `/`. Сервер принимает в теле запроса строку URL в формате `text/plain` и возвращает сокращённый URL в формате `text/plain` со статусом `201 Created`.

Пример запроса:

```http
POST / HTTP/1.1
Host: localhost:8080
Content-Type: text/plain

https://practicum.yandex.ru/
```

Пример ответа:

```http
HTTP/1.1 201 Created
Content-Type: text/plain
Content-Length: 30

http://localhost:8080/EwHXdJfB
```

Для перехода по короткой ссылке используется эндпоинт с методом `GET` и путём `/{short}`, где `short` — идентификатор сокращённого URL, например `/EwHXdJfB`. В случае успешной обработки запроса сервер возвращает статус `307 Temporary Redirect` и оригинальный URL в HTTP-заголовке `Location`.

Пример запроса:

```http
GET /EwHXdJfB HTTP/1.1
Host: localhost:8080
Content-Type: text/plain
```

Пример ответа:

```http
HTTP/1.1 307 Temporary Redirect
Location: https://practicum.yandex.ru/
```

В проекте используется `net/http` и роутер `chi`. Логика разделена на несколько слоёв: HTTP-обработчики принимают запросы и формируют ответы, сервисный слой отвечает за валидацию URL и генерацию коротких идентификаторов, repository-слой хранит соответствие между короткой и оригинальной ссылкой. Для генерации идентификаторов используется base62-кодирование, а для хранения данных — потокобезопасное in-memory-хранилище на `map` и `sync.RWMutex`.

Стек проекта: `Go`, `net/http`, `chi`, `in-memory storage`, `sync.RWMutex`.

Для запуска проекта нужно склонировать репозиторий и выполнить команду:

```bash
go run ./cmd/shortener
```

После запуска сервис доступен по адресу `http://localhost:8080`.

В этом проекте реализована базовая backend-логика сервиса сокращения ссылок: обработка HTTP-запросов, валидация входных данных, генерация коротких идентификаторов, хранение ссылок в памяти и редирект на оригинальный URL. Проект можно развивать дальше: добавить постоянное хранение данных в базе, конфигурацию через переменные окружения, логирование, тесты и Dockerfile.
